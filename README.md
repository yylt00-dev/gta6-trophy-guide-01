An offline GTA 6 trophy guide and tracker covering all 55 PS5 trophies, with a cited guide for each one, a roadmap to the platinum, missable flags, and progress saved in the browser with export and import.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — the guide works with the network off; every file it loads is under `app/`.
